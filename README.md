# Pratibimba – Bengaluru Region (static site)

## Deploy on GitHub Pages (free)
1. Create a repo, upload everything in this folder (index.html at the root).
2. Settings → Pages → Source: "Deploy from a branch" → main / (root) → Save.
3. Site goes live at https://<username>.github.io/<repo>/

## Edit content
- All Kannada + English text: `js/data.js` (kn / en side by side)
- Add gallery pictures: copy image into `assets/gallery/`, add one line to GALLERY in `js/data.js`
- Colours & layout: `css/style.css`
